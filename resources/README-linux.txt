Аленка Modern 2.0.2 — клавиатурный тренажёр для Linux

Установка пакета Debian/Ubuntu

sudo apt install ./alenka-modern-2.0.2-linux-amd64.deb
Для 32-битной системы выберите пакет i386.
Запускайте «Алёнку Modern» из меню приложений или командой alenka.
Сохранения находятся в $XDG_DATA_HOME/alenka-modern либо
в ~/.local/share/alenka-modern, если XDG_DATA_HOME не задана.
Пакет не удаляет сохранения при обновлении и удалении программы.

Запуск AppImage

Для 64-битной системы выберите x86_64, для 32-битной — i686.
chmod +x alenka-modern-2.0.2-x86_64.AppImage
./alenka-modern-2.0.2-x86_64.AppImage
SDL2 и библиотека C++ включены в AppImage. Сохранения находятся в том же
пользовательском каталоге, что и у deb; файл AppImage можно переносить.
Не запускайте программу через sudo.
Если в системе недоступен FUSE, используйте:
./alenka-modern-2.0.2-x86_64.AppImage --appimage-extract-and-run

Запуск из tar.gz

Установите системную SDL2: sudo apt install libsdl2-2.0-0
Распакуйте архив целиком. В терминале перейдите в распакованную папку alenka
и выполните ./alenka. Каталог data должен оставаться рядом с программой.
Для этой поставки profiles/<id>.ini, alenka.ini и .alenka.lock создаются
в текущей рабочей папке запуска. Она должна быть доступна для записи.
Не запускайте программу через sudo.

Управление

Enter или пробел — продолжить с заставки. Enter или Esc — закрыть стартовую справку.
F1 — справка; влево/вправо в справке — исходная страница / профили.
Стрелки — выбор и изменение настроек. Пробел — выполнить действие.
Enter — начать упражнение или вернуться в меню.
Два Shift — переключить раскладку ввода. Поле «Язык» переключает РУС/ENG курс.
Esc при наборе — меню; Esc в меню — статистика; Esc в справке — назад.
Alt+Enter — оконный / полноэкранный режим. Alt+F4 — сохранить и выйти.
Поле «Звук» — включить или выключить сигналы ошибки и метроном.
Без аудиоустройства программа продолжает работать.

Профили

В поле «Профиль» вверх/вниз или пробел открывают «Переименовать / Сменить».
Enter подтверждает действие, Esc отменяет. Имя вводится в системной раскладке.
Прогресс русского и английского курсов сохраняется независимо.
Сохранение выполняется после строки, смены настроек и перед закрытием.
При ошибке записи можно повторить сохранение, отменить действие или явно
выйти без сохранения. Повреждённые профили не перезаписываются.
Для переноса сохранений скопируйте profiles и alenka.ini при закрытой программе.

Английский курс встроен в программу. Финал: Kenneth Grahame,
The Wind in the Willows (1908), глава V «Dulce Domum».

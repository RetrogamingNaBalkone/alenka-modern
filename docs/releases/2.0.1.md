# Аленка Modern 2.0.1

Клавиатурный тренажёр теперь доступен для Windows x64 и Linux amd64/i386.
Linux-пакеты собираются на базе Ubuntu 18.04; 64-битный пакет дополнительно
проверяется на Ubuntu 24.04. DOSBox для работы не нужен.

## Скачать и запустить

| Система | Файл | Запуск |
| --- | --- | --- |
| Windows, 64 бита | `alenka-modern-2.0.1-windows-x64.zip` | Распаковать целиком, открыть `alenka.exe` |
| Linux, 64 бита | `alenka-modern-2.0.1-linux-amd64.deb` | Установить через `sudo apt install ./имя-пакета.deb`, запустить `alenka` |
| Linux, 32 бита | `alenka-modern-2.0.1-linux-i386.deb` | Установить на 32-битной системе тем же способом |
| Linux, архив | `alenka-modern-2.0.1-linux-<arch>.tar.gz` | Установить `libsdl2-2.0-0`, распаковать, перейти в папку `alenka`, выполнить `./alenka` |

Выбирайте файл для своей архитектуры. Linux-архив использует системные SDL2
и стандартную библиотеку C++; пакет `.deb` устанавливает нужные зависимости автоматически.
Контрольные суммы поставляются в файлах `.sha256`.

## Изменения

- Добавлены сборки Linux amd64 и i386, пакеты `.deb` и архивы `.tar.gz`.
- Добавлены меню запуска и пользовательский каталог сохранений для установленного Linux-пакета.
- Обеспечена совместимость исходного кода со штатной SDL2 Ubuntu 18.04.
- Таймер использует 64-битное монотонное время без обнуления через 49,7 суток.
- Добавлены автоматические сборки, проверки ресурсов, интерфейса и установленных Linux-пакетов.

## Сохранения

Windows и Linux-архив сохраняют `profiles`, `alenka.ini` и `.alenka.lock`
в текущей рабочей папке запуска. Установленный Linux-пакет использует
`$XDG_DATA_HOME/alenka-modern` либо `~/.local/share/alenka-modern`.
Для переноса скопируйте `profiles` и `alenka.ini` при закрытой программе.
Формат профилей версии 2.0 сохранён.

## Управление

Стрелки выбирают поля и меняют настройки; пробел выполняет действие.
Enter начинает упражнение, Esc возвращает в меню. F1 открывает справку.
Два Shift переключают раскладку ввода, поле «Язык» — русский и английский курсы.
Alt+Enter переключает оконный и полноэкранный режимы; Alt+F4 сохраняет и закрывает программу.
Управление профилями и звуком доступно в верхнем меню.

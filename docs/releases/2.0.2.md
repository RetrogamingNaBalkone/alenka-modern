# Аленка Modern 2.0.2

В этой версии исправлена упаковка Linux,
добавлены AppImage для 64- и 32-битных систем и значок приложения.

## Изменения

- Ресурсы deb перенесены из `/usr/lib` в `/usr/share/alenka-modern`,
  документация — в `/usr/share/doc/alenka-modern`.
- Добавлена явная сборка i386 на amd64 через GCC multilib. CI проверяет
  её отдельно от нативной 32-битной сборки, включая архитектуру ELF и deb.
- Добавлены AppImage со встроенными SDL2 и библиотекой C++, desktop-файлом,
  значком, AppStream-метаданными и сведениями о лицензиях библиотек.
- Значок на основе исходной пиксельной буквы «А» используется в окне,
  Linux-меню и Windows EXE.

## Файлы и запуск

| Формат | Файл | Запуск |
| --- | --- | --- |
| Windows, 64 бита | `alenka-modern-2.0.2-windows-x64.zip` | Распаковать целиком и открыть `alenka.exe` |
| AppImage, 64 бита | `alenka-modern-2.0.2-x86_64.AppImage` | Сделать исполняемым и запустить |
| AppImage, 32 бита | `alenka-modern-2.0.2-i686.AppImage` | То же для 32-битной системы |
| Debian/Ubuntu | `alenka-modern-2.0.2-linux-<arch>.deb` | `sudo apt install ./имя.deb`, затем `alenka` |
| Архив | `alenka-modern-2.0.2-linux-<arch>.tar.gz` | Установить `libsdl2-2.0-0`, распаковать целиком и запустить `./alenka` из его папки |

`<arch>` — `amd64` или `i386`. Контрольные суммы находятся в файлах `.sha256`.
Linux-поставки собираются на Ubuntu 18.04. Для amd64 дополнительно проверяется
запуск deb и AppImage на Ubuntu 24.04; AppImage проверяется без системной SDL2.

```sh
chmod +x alenka-modern-2.0.2-x86_64.AppImage
./alenka-modern-2.0.2-x86_64.AppImage
```

Если FUSE недоступен:

```sh
./alenka-modern-2.0.2-x86_64.AppImage --appimage-extract-and-run
```

AppImage и установленный deb сохраняют профили в `$XDG_DATA_HOME/alenka-modern`
либо `~/.local/share/alenka-modern`. Перенос или замена файла AppImage не удаляет
профили. Закройте один экземпляр перед запуском другого формата из того же
каталога сохранений. Формат профилей и управление из 2.0.1 сохранены.

## Проверка перед выпуском

8 ноября 2026 года локально проверены:

- 12 CTest-проверок в Ubuntu 18.04 amd64, Ubuntu 18.04 i386,
  при сборке amd64 → i386 и современным компилятором Ubuntu 24.04.
- 13 Python-тестов упаковки и ресурсов на обеих архитектурах Bionic.
- Установка deb и запуск launcher от обычного пользователя, включая
  кросс-собранный пакет и установку Bionic amd64-пакета на Ubuntu 24.04.
- AppImage обеих архитектур: перенос в путь с пробелами, запуск из `/usr`,
  SDL-ввод, изменение звука, сохранение профиля и повторный запуск.
- AppImage amd64 на чистой Ubuntu 24.04 без системной SDL2; режимы
  извлечения и `--appimage-extract-and-run`. FUSE-запуск проверен в WSL 2.
- Windows: полная сборка, проверки звука, профилей, DOS-поведения,
  DPI/input, SDL smoke и состава ZIP.

Журналы Linux-проверок находятся локально в `diagnostics/validation/2.0.2`.
Процесс GitHub Actions обновлён для повторения этих проверок после отправки
изменений в репозиторий; публикация релиза выполняется отдельно.

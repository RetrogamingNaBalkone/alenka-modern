# Аленка Modern 1.0

Классический клавиатурный тренажёр «Аленка» теперь работает в современной Windows — без DOSBox и установки. Сохранены знакомое оформление, упражнения и управление с клавиатуры.

## Что есть в версии 1.0

- Упражнения для русской и английской раскладок.
- Подсветка клавиш, три режима подсказок, настройки сложности, опечаток и ритма.
- Статистика набора с возможностью обнуления.
- Оконный и полноэкранный режимы, поддержка масштабирования Windows.

## Как запустить

Скачайте **alenka-modern-1.0-windows-x64.zip**, распакуйте архив целиком в любую папку и запустите **alenka.exe**. Папка `data` и файл `SDL2.dll` должны оставаться рядом с программой. Сборка предназначена для 64-битной Windows.

## Основные клавиши

- **Enter / пробел** — продолжить с заставки.
- **F1** — справка.
- **Стрелки** — выбор и изменение настроек; **пробел** — выполнить действие.
- **Enter** — начать упражнение или вернуться в меню.
- **Два Shift одновременно** — сменить русскую и английскую раскладки.
- **Esc** — открыть статистику; повторный **Esc** — выйти.
- **Alt+Enter** — переключить оконный и полноэкранный режимы.
- **Alt+F4** — закрыть программу.

## Особенности

Статистика сохраняется только до закрытия программы. Звук, печать и сохранение не добавлены: соответствующие пункты показывают исходное сообщение «Не реализовано!!!». Поле имени не используется.

В этом релизе опубликована готовая сборка для Windows. Готовой сборки для Linux пока нет.
